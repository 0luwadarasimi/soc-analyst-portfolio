# Quest 3: Splunk SIEM Detections on Cowrie Honeypot Logs

## Overview
Built a Splunk dashboard to analyze attacker behavior captured by a Cowrie SSH honeypot, focused on login activity and command execution.

## Setup
- Splunk Enterprise 10.4.2 on Ubuntu Server VM
- Cowrie honeypot logs ingested into a dedicated `cowrie` index
- Synthetic attack sessions generated via local SSH connections

## Panel 1: Login Attempts — Success vs Fail
**SPL:** `index=cowrie (eventid=cowrie.login.success OR eventid=cowrie.login.failed) | stats count by eventid`

![Dashboard](dashboard-overview.jpg)

## Panel 2: Commands Typed by Attacker
**SPL:** `index=cowrie eventid=cowrie.command.input | table _time, session, input`

## Note
All traffic in this lab is synthetic, generated by a single source (localhost SSH sessions) for demonstration purposes only.

## Skills Demonstrated
- SIEM log ingestion and index configuration
- SPL query writing for security event analysis
- Honeypot data analysis and attacker behavior tracking
