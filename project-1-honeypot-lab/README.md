# Network Attack Detection & Reporting — Honeypot Lab

## Overview
This project simulates an attacker scanning and targeting a vulnerable 
SSH service, captured and analyzed using a honeypot and packet capture tools.

## Environment
- Kali Linux (attacker VM)
- Ubuntu Server running Cowrie SSH honeypot (target VM)
- VirtualBox host-only networking
- Wireshark for traffic capture
- Nmap for scanning

## Objectives
- Configure isolated lab network
- Perform reconnaissance and attack simulation
- Capture and analyze malicious traffic
- Write incident report based on findings
